# PPT Generator Changelog

## v1.0 (2026-07-30)
- 完成 DOCX → PPT 自动生成
- 支持广发策略模板
- 支持网页上传生成
- 支持图表、图片、表格自动排版
- 支持 summary / risk / thanks 页面

## v1.1 (进行中)
目标：
- 优化图片分组逻辑
- 优化表格排版
- 不改变核心生成流程

图文匹配推荐版：
- 按章节和相邻图表边界划分论证单元，不再固定截取“前3后2”段落
- 使用结构位置、语义相关性、结论强度、指标重合度和完整性连续评分
- 新增指代不明、方法说明和问句扣分
- 输出核心结论、支持证据和高/中/低置信度
- 多图容器按图题拆分，页面层统一去重并控制为最多2条文字

规范模板对齐优化：
- 页面规划改为保留原文顺序索引，让论点、图表、紧随其后的结论按连续论证块进入同一页
- 紧邻图表与小型原生表格允许组合排版，避免同一组 CPI 证据被机械拆页
- 核心结论压缩为最多5条；封面长标题优先在破折号前换行
- 普通页标题与正文继承模板占位符字号、字体和颜色，不再强制覆盖模板视觉规范
- 正文高度改用换行估算，降低正文与图表、表格发生视觉挤压的风险
- 清理正文中的“图N：/表N：”残留，并优先使用图题生成多页内容的差异化标题
- 核心结论恢复“要点段落 + 空白段落”的模板节奏，避免多条结论紧贴
- 正文分析页强制至少包含一个源图、源表或源图片；纯文字小节不再单独生成正文页

核心结论：段与段之间空行格式


修改原则：
- 单文件修改
- 单功能修改
- 每次修改后测试生成
